# INFO-1165 — Modelos de Regresión Lineal y GAM

Proyecto grupal de Estadística Computacional (Universidad Católica de Temuco).

* **Fuente de datos:** Kaggle — *California Housing Prices* (`camnugent/california-housing-prices`), muestra limpia de 10,000 registros (80% entrenamiento / 20% prueba).
* **Archivos:** `Datos_Viviendas_Limpios.csv` (base procesada) y `analisis_regresion.R` (script completo).

## Cómo ejecutar
1. Clonar el repositorio y abrir `INFO1165-regresion.Rproj` en RStudio.
2. Abrir `analisis_regresion.R` y ejecutarlo completo (`Ctrl + A` y `Ctrl + Enter`, o clic en **Source**). El script instala las librerías faltantes automáticamente.
